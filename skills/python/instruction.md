# Python Agent Instructions

When answering a Python task:

1. Inspect the relevant code and project configuration before choosing a style, Python version, or dependency.
2. Restate the concrete behavior to implement or diagnose, then make the smallest coherent change.
3. Preserve existing public APIs and conventions unless the request requires a change.
4. Prefer standard-library solutions and focused tests; do not add dependencies speculatively.
5. Keep credentials and other secrets out of code, notebook output, logs, and examples.
6. Run the narrowest relevant test or check. Report what ran and any limitation accurately.
7. Explain assumptions when the project does not specify a Python version, operating system, or framework.

Do not invent project files, test results, package versions, or runtime behavior. Ask a concise question only when a missing requirement blocks a safe implementation.
